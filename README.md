## 📚 Course Directory & Highlights

### 1st Bachelor

#### [Semester 1 (`1e-bach-sem1/`)](1e-bach-sem1/README.md)
- **[`Lam/`](1e-bach-sem1/Lam/) (Lineaire Algebra en Meetkunde)**:
  Comprehensive LaTeX proof compilation (`Bewijzen/main.tex`), theorem and definition overviews, instructive counterexamples for oral exams, and interactive Jupyter notebooks covering homomorphisms, coordinate transformations, and inner product spaces.
- **[`Chemie 2/`](1e-bach-sem1/Chemie%202/)**:
  Chemical thermodynamics (enthalpy, entropy, Gibbs free energy, equilibria, electrochemistry), interactive HTML flashcards, and computational notebooks.

#### [Semester 2 (`1e-bach-sem2/`)](1e-bach-sem2/README.md)
- **[`Sterren-en-Planeten/`](1e-bach-sem2/Sterren-en-Planeten/)**:
  Spherical astronomy and coordinate transformations (Horizontal, Equatorial, Ecliptic), sidereal time calculations, culmination and circumpolar conditions, stellar magnitudes, radiation laws, and comprehensive LaTeX cheatsheets.

---

### 2nd Bachelor

#### [Semester 1 (`2e-bach-sem1/`)](2e-bach-sem1/README.md)
- **[`Biophysics/`](2e-bach-sem1/Biophysics/)**: Dynamical systems modeling in biophysics, Hopf bifurcations, Rössler attractors, numerical phase portraits, and exam problem models.
- **[`Kwantum/`](2e-bach-sem1/Kwantum/) (Kwantummechanica I)**: Core axioms, Schrödinger wave mechanics, 1D potentials, harmonic oscillator, and markdown study outlines.
- **[`Py4sci/`](2e-bach-sem1/Py4sci/) (Python for Scientists)**: In-depth computational physics exercises, modular chapter guides (NumPy, SciPy, Matplotlib, Monte Carlo integration, Fourier transforms), and exam preparations.
- **[`Statistiek/`](2e-bach-sem1/Statistiek/)**: Probability distributions, statistical estimators, hypothesis testing, confidence intervals, theorem proofs, and problem solutions.
- **[`VFR/`](2e-bach-sem1/VFR/) (Vector- en Functieruimten)**: Infinite-dimensional Hilbert spaces, linear operators, spectral theorem, Fourier series, distributions, and interactive Reveal.js slides.

#### [Semester 2 (`2e-bach-sem2/`)](2e-bach-sem2/README.md)
- **[`Exp-2/`](2e-bach-sem2/Exp-2/) (Experimentele Fysica 2)**: Observational astronomy practicum analyzing Hertzsprung-Russell (HR) cluster diagrams and photometry.
- **[`Groepen-en-Representaties/`](2e-bach-sem2/Groepen-en-Representaties/)**: Symmetry in physics, Lie groups ($SO(3)$, $SU(2)$, Lorentz group), Lie algebras, representations, and character tables.
- **[`Materiaal-Fysica/`](2e-bach-sem2/Materiaal-Fysica/)**: Crystallography, Bravais lattices, 2D plane groups, 3D point groups, and unit cell symmetry notes.
- **[`REM/`](2e-bach-sem2/REM/) (Relativiteit en Elektromagnetisme)**: Special relativity, relativistic 4-vector kinematics, covariant electrodynamics, electromagnetic waveguides (Gmsh meshes), and exam cheatsheets.
- **[`Sterrenstelsels/`](2e-bach-sem2/Sterrenstelsels/)**: Galactic structure, Jeans equations, rotation curves, dark matter halos, gravitational potential theory, and numerical galactic models.
- **[`Thermische-Fysica/`](2e-bach-sem2/Thermische-Fysica/)**: Classical thermodynamics, Legendre transforms, Maxwell relations, real gases, phase transitions, and worked exam sets.

### 3rd Bachelor

#### [Semester 1 (`3e-bach-sem1/`)](3e-bach-sem1/README.md)
- **[`Complexe Analyse/`](3e-bach-sem1/Complexe%20Analyse/)**:
  - Modular LaTeX book rewrite (`Theorie/Cursus/`) across 7 chapters: Complex numbers, Analytic functions, Elementary functions, Complex contour integration, Series representations (Taylor & Laurent), Residue calculus, and Conformal maps.
  - Python scripts for plotting multivalued functions, Riemann surfaces, and conformal grids (`Oefeningen/Python/`).
  - Detailed analysis of challenging exam problems (`Moeilijkheden/`).
- **[`Kwantum II/`](3e-bach-sem1/Kwantum%20II/) (Kwantummechanica II)**:
  - Advanced quantum mechanics: stationary perturbation theory (non-degenerate & degenerate), variational methods, WKB approximation, time-dependent perturbation theory, Fermi's golden rule, and scattering theory.
  - Archival exam papers spanning 2007–2021 and detailed proof outlines.
- **[`Statistische/`](3e-bach-sem1/Statistische/) (Statistische Fysica)**:
  - Ensembles (Microcanonical, Canonical, Grand Canonical), partition functions, and thermodynamic potentials.
  - Computational Jupyter notebooks: degenerate Fermi gas, Bose-Einstein condensation ($T_c$, heat capacity), Debye specific heat of solids, second virial coefficients, and paramagnetism.
  - Problem sets Reeks 1–7 and historical literature papers (BEC, Gibbs paradox).
- **[`Misc/`](3e-bach-sem1/Misc/)**: Timetable rosters and exam planning.

#### [Semester 2 (`3e-bach-sem2/`)](3e-bach-sem2/README.md)
- **[`Atoom&Moleculaire Fysica/`](3e-bach-sem2/Atoom&Moleculaire%20Fysica/)**: Multi-electron systems, spin-orbit coupling, molecular bonding, and spectroscopy.
- **[`Elementary Particle Physics/`](3e-bach-sem2/Elementary%20Particle%20Physics/)**: Standard Model phenomenology, particle interactions, gauge symmetries, and conservation laws.
- **[`Nuclear Physics/`](3e-bach-sem2/Nuclear%20Physics/)**: Nuclear models (liquid drop, shell model), decay modes, and nuclear cross sections.
- **[`Vaste Stof/`](3e-bach-sem2/Vaste%20Stof/)**: Condensed matter physics, crystal lattices, band theory (Bloch theorem), and semiconductor physics.

## 🚀 Getting Started & Setup

### 1. Prerequisites
- **Python 3.10+** (tested on macOS / Linux)
- **LaTeX distribution** (MacTeX / TeX Live) for compiling `.tex` documents
- **Git** with `pre-commit`

### 2. Environment Setup

```bash
# Clone the repository
git clone https://github.com/trcools/VSC_macbook_tristan.git
cd VSC_macbook_tristan

# Create and activate a Python virtual environment
python3 -m venv .venv
source .venv/bin/activate

# Install dependencies (NumPy, SciPy, Matplotlib, SymPy, Plotly, Astropy, etc.)
pip install -r requirements.txt

# Install pre-commit hooks
pre-commit install
```

### 3. Running Notebooks

Launch Jupyter Lab to explore the computational models:
```bash
jupyter lab
```

### 4. Compiling LaTeX Documents

All LaTeX documents are configured for compilation with `pdflatex` or `latexmk`:
```bash
# Example: Compile Complex Analysis notes
cd "3e-bach-sem1/Complexe Analyse/Theorie/Cursus"
latexmk -pdf main.tex

# Clean temporary build artifacts
latexmk -c
```

## 🔒 Academic Integrity & Security

Please consult **[SECURITY.md](SECURITY.md)** for detailed repository guidelines.

- **Private course materials** (professor lecture slides, copyrighted textbooks, exam papers) are strictly kept out of version control and stored in local `_lokaal/` directories ignored by Git.
- **Self-authored material only**: All committed notes, summaries, derivations, and Python scripts represent original work.
- **Large binary files**: Video recordings (`*.mp4`) and large binary blobs are excluded via `.gitignore`.
